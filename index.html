CENTRAL SECURITY & CONNECTED PLATFORMS

Every committee website signs students in through this portal. A committee shows Securely Connected only after the server has verified it. Step by step: 1) save the committee's website link in the Committees tab, 2) Configure integration, 3) put the credentials into that committee's Supabase project, 4) Test connection.

Verified student roster

Students sign in with a one-time code sent to the email listed here. The server maps that verified email to one student ID, so nobody can type or switch to another ID. Upload an Excel or CSV file with the columns “Index Number”, “Name” and “Email”.
